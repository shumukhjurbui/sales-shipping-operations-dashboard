# Sales & Shipping Operations Dashboard

An interactive **Microsoft Excel** operations dashboard and management analysis report reviewing **501 order transactions** across **7 Saudi regions (17 cities)** from **January 3, 2024 to May 30, 2026**.

## Project Overview

This project transforms raw sales, order, payment, and shipping records into an executive-ready monitoring dashboard and management report. It tracks revenue performance, fulfillment status, shipping duration, and operational bottlenecks to support data-driven administrative decisions.

## Key Performance Indicators (KPIs)

| Metric | Value |
| :--- | :--- |
| **Total Sales Revenue** | SAR 3,926,780 |
| **Net Profit After Discount** | SAR 425,572 (10.8% margin) |
| **Total Recorded Orders** | 501 (39,387 units) |
| **Delivered Orders** | 118 (23.6%) |
| **Cancelled Orders** | 139 (27.7%) |
| **Average Shipping Duration** | 2.58 days |
| **Total Shipping Cost** | SAR 33,676 (Avg. SAR 67.22/order) |

## Key Operational Insights

- **Top Performing Region:** Eastern Region led revenue at **SAR 620,018 (15.8%)**, followed closely by Jazan (**SAR 599,670**) and Medina (**SAR 590,845**).
- **Top Product Category:** Bookcases generated the highest sales at **SAR 1,102,910 (28.1%)**, followed by Tables (**SAR 1,046,906 | 26.7%**).
- **Order Status & Cancellations:** Cancelled orders (**27.7%**) exceeded delivered orders (**23.6%**), with cancellations most concentrated in **Abha (38.2%)**, **Jazan (34.2%)**, **Medina (28.9%)**, and **Sabya (28.9%)**.
- **Shipping Efficiency:** **Same Day** was the most used tier (**193 orders | 1.00 day avg.**), **Express** averaged **1.99 days** (**153 orders**), and **Standard** averaged **5.12 days** (**155 orders**).
- **Payment Distribution:** Evenly balanced across **Credit Card (168)**, **Cash (167)**, and **Online Payment (166)**.
